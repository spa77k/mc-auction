# AuctionHouse

Paper 26.1.2 向けのオークションプラグイン。プレイヤー同士が単品アイテムを英式入札(+即決価格)で売買できる仕組みをチェストGUIで提供する。

エンチャント品のように相場が立たない単品や、他者があまり売っていない物は、既存のチェストショップ(QuickShop-Hikari)では価格設定に困る。手数料が高くてもよいので `/irai` のように動くオークションが欲しい、という要望に応えたもの。QuickShop-Hikariは置き換えず併存させ、定番品の常設販売はQuickShop、相場が立たない単品はオークション、という住み分けを想定している。

## 特徴

- `/ah`(エイリアス `/auction`)コマンドでどこからでもチェストGUIのオークションハウスを開ける
- 出品・一覧閲覧・入札・即決購入・保管庫からの受け取りをGUI上で完結
- 落札方式は英式入札 + 即決価格の併用。即決価格に達した時点で即座に落札が成立する
- 代金はVault経由の経済プラグイン通貨のみ(アイテム報酬なし)
- 出品時に出品料(前払い・返金なし)、落札時に成約手数料を徴収する。徴収分は消滅し、運営口座等へは送金しない
- 入札金は入札した瞬間にプラグインの拘束として即座に引き落とされ、上回られた入札は即座に全額自動返金される
- 終了間際の入札があった場合は自動的に終了時刻を延長する(スナイプ対策、延長回数の上限あり)
- 落札品・売れ残りの返却品はプラグインが保管庫として預かり、本人がGUIから受け取る(足元へのドロップはしない)
- 落札代金はVault経済へ直接入金する(保管庫を経由しない)。オフライン中に発生した通知は溜めておき、次回ログイン時にまとめて届ける
- 出品の取り消しは入札が0件のときだけ可能。出品料は返らない
- 出品一覧は並び替え(終了間近 / 新着 / 価格が安い順 / 価格が高い順)に対応
- SQLiteによる永続化(単一ファイル、サーバー再起動後もデータを保持)
- 出品・入札のチャット入力中の発言は全体チャットにもDiscord等の連携先にも流れない

## 動作要件

- Paper 26.1.2 以降
- Vault、および対応する経済プラグイン(EssentialsX等)
- Java 25(Paper 26.1系以降)

## コマンド

| コマンド | 説明 |
| --- | --- |
| `/ah` | オークションハウスのメインメニューを開く |
| `/ah sell` | 手に持っているアイテムの出品手続きを開始する(チャット入力形式) |
| `/ah list` | 出品中のアイテム一覧を開く |
| `/ah my` | 自分の出品一覧を開く |
| `/ah bids` | 自分が入札中の出品一覧を開く |
| `/ah vault` | 保管庫を開く |
| `/ah cancel` | 進行中の出品・入札のチャット入力をキャンセルする |
| `/ah admin cancel <出品ID>` | (`auction.admin`権限)出品を強制的に取り消し、アイテムと入札金を関係者へ返却する |

## GUI操作

`/ah` で開くチェストGUIだけで、出品開始・閲覧・入札・即決購入・保管庫からの受け取りまで一通りの操作ができる。サブコマンドはGUIの各画面へのショートカット。GUI内のアイテムは取り出せない(クリックはすべてキャンセルされる)。

### チャット入力形式(出品・入札)について

出品の個数・開始価格・即決価格・出品期間・最終確認、および入札額の入力は、通常のチャットではなくBukkitの会話(Conversation)モードで受け取る。この間の入力はオークションハウスだけが受け取り、全体チャットやDiscord連携先には流れない。`auction.input-timeout-seconds`(既定120秒)を超えて入力がない場合は自動的にキャンセルされる(出品の場合、まだアイテムも代金も動いていないため損失はない)。

### メインメニュー(`/ah`)

| アイテム | 操作 |
| --- | --- |
| 本「出品を探す」 | 出品中のアイテム一覧を開く(`/ah list` と同じ) |
| 金塊「出品する」 | GUIを閉じ、手に持っているアイテムの出品手続きを開始する(`/ah sell` と同じ) |
| 名札「自分の出品」 | 自分が出品したアイテムの一覧を開く(`/ah my` と同じ) |
| 金インゴット「入札中」 | 自分が入札した出品の一覧を開く(`/ah bids` と同じ) |
| チェスト「保管庫」 | 受け取り待ちのアイテムを開く(`/ah vault` と同じ) |

### 出品する

1. 手に何も持っていない場合、禁止マテリアルの場合、同時出品数の上限(既定3件)に達している場合はいずれも出品できない
2. GUIを閉じ、チャット入力で「個数(そのままEnterで全部)→開始価格→即決価格(不要なら0か「なし」)→出品期間(6/12/24/48時間から選択)」の順に質問される
3. 最後に出品料を提示した確認が出るので「はい」で確定、「いいえ」でキャンセル(この時点まではアイテムも代金も動かない)
4. 「はい」の時点で手持ちのアイテムが出品開始時から変わっていないか、出品料を払えるかを再確認したうえで、出品料を徴収してアイテムをインベントリから減算し、出品を作成する
5. 出品すると全体チャットに告知される

### 出品一覧

- 出品中のアイテムを1ページ45件まで、実際のアイテムそのもので表示し、lore に出品者・個数・現在価格・即決価格・入札数・残り時間を追記する
- 出品をクリックすると詳細画面を開く
- 並び替えボタンで「終了間近 / 新着 / 価格が安い順 / 価格が高い順」を循環できる
- 矢印で前後のページへ移動、バリアでメインメニューへ戻る
- 出品中のアイテムが1件もない場合はチャットにその旨が表示される

### 出品の詳細

- 中央のアイテムに出品者・個数・状態・開始価格・現在価格・即決価格・入札数・最高入札者・残り時間を表示する
- 出品中かつ自分の出品でなければ、緑の羊毛「入札する」でチャット入力による入札ができる
- 即決価格が設定されていれば、金インゴット「即決で買う」から確認画面を経て即決購入できる
- 自分の出品かつ入札が0件のときだけ、赤の羊毛「出品を取り消す」で取り消せる(出品料は返らない)

### 入札

- 「入札する」を選ぶとチャット入力で金額を聞かれる(最低入札額は開始価格、または入札がある場合は現在価格+最低上げ幅)
- 入札額を入力すると即座にその金額が引き落とされる。それまでの最高入札者がいた場合、その入札額は即座に全額返金され、上回られた旨が通知される(オフラインの場合は次回ログイン時に通知)
- 入札額が即決価格以上になった場合は、自動的に即決価格での即時落札として処理される
- 終了まで残り3分以内(既定)の入札があった場合、終了時刻が3分(既定)延長される。延長は最大10回(既定)まで、延長時は全体チャットと出品者へ通知される

### 即決購入

- 「即決で買う」から確認画面を開き、「はい、購入する」で即決価格を即座に支払って落札する
- それまでの最高入札者がいた場合は入札額を全額返金する
- 落札するとアイテムは自分の保管庫へ、代金(手数料差引後)は出品者のVault残高へ即座に入金される。全体チャットに告知される

### 自分の出品 / 入札中

- 「自分の出品」には自分が出品したアイテムを状態付きで一覧表示する。出品中かつ入札0件のものはクリックで直接取り消せる。それ以外はクリックで詳細画面を開く
- 「入札中」には自分が入札したことのある出品を一覧表示する。最高額入札者かどうか、落札できたかどうかをloreで確認できる。クリックで詳細画面を開く

### 保管庫

- 落札品・売れ残りの返却品・取り消し品を1ページ45件まで表示する
- アイテムをクリックすると受け取る。インベントリに空きがない場合は「空きがありません」と表示され、受け取れなかった分は保管庫に残る(足元へのドロップはしない)
- 無期限保持(出品の履歴レコードとは異なり、保持期間による自動削除の対象外)

## 手数料の説明

- **出品料**: 開始価格の5%(既定、`auction.listing-fee-rate`)。ただし`auction.listing-fee-min`(既定100)を下回らない。出品確定時に出品者から徴収し消滅する。売れ残り・取り消し・落札のいずれでも返還しない
- **成約手数料**: 落札額の10%(既定、`auction.sale-fee-rate`)。落札成立時に落札額から差し引き、残額を出品者へ入金する。差し引いた分は消滅する
- 金額はすべて整数として扱う。手数料計算は切り上げ(`ceil`)で統一する

## 権限

| 権限 | 説明 | デフォルト |
| --- | --- | --- |
| `auction.use` | オークションハウスの利用(出品・入札・保管庫の利用) | true(全員) |
| `auction.admin` | 不正出品の強制終了と返却(`/ah admin cancel`) | op |

## ビルド方法

```bash
mvn package
```

`target/auctionhouse-1.0.0.jar` が生成されるので、サーバーの `plugins` フォルダに配置する。

## Dockerでの簡易テスト

Docker daemon が起動している状態で、次のスクリプトを実行すると Paper 26.1.2 のテストサーバーを Java 25 で起動し、AuctionHouse・Vault・EssentialsX の読み込み、`/ah` のプレイヤー専用チェック、SQLite テーブル作成を確認できる。

```bash
./scripts/test-plugin.sh
```

サーバーは `25565` 番ポートで起動したままになり、データは `server-data-26.1.2/` に保存される。停止する場合は次を実行する。

```bash
docker compose down
```

## 設定 (`config.yml`)

- `auction.min-price` / `auction.max-price`: 開始価格の下限・上限
- `auction.max-listings-per-player`: 1人が同時に出品できる件数(既定3)
- `auction.durations-hours`: 出品期間として選べる時間のリスト(既定 6/12/24/48)
- `auction.listing-fee-rate` / `auction.listing-fee-min`: 出品料の税率と最低額
- `auction.sale-fee-rate`: 成約手数料の税率
- `auction.min-increment-rate` / `auction.min-increment-flat`: 最低入札上げ幅(率と定額の大きい方)
- `auction.extension-threshold-seconds` / `auction.extension-seconds` / `auction.max-extensions`: スナイプ対策の自動延長の閾値・延長幅・最大回数
- `auction.input-timeout-seconds`: 出品・入札のチャット入力を何秒放置したら自動キャンセルするか
- `auction.retention-days`: 終了済み出品(落札・売れ残り・取消)の履歴を何日後にデータベースから削除するか(既定30日、0以下で無効化)。保管庫は対象外で無期限保持
- `auction.banned-materials`: 出品を禁止するマテリアル名のリスト(既定は空、制限なし)
- `check-interval-seconds`: 終了処理・延長チェックの実行間隔(秒、既定5秒)
- `messages`: 各種メッセージ文言(日本語固定)

## 使い方の流れ

1. 出品者が手にアイテムを持って `/ah sell` を実行し、個数・開始価格・即決価格・出品期間をチャット入力して出品を確定する(出品料が徴収され、アイテムはオークションハウスに預けられる)
2. 入札者が `/ah list` から出品を選んでチャット入力で入札する(入札額は即座に拘束され、上回られると即座に返金される)
3. 即決価格以上の入札、またはGUIからの即決購入で即座に落札が成立する。入札のみで終了時刻を迎えた場合も、最高額入札者が落札者になる
4. 落札が成立すると、落札者の保管庫にアイテムが入り、出品者のVault残高へ成約手数料を差し引いた代金が入金される
5. 入札が1件もないまま出品期間が終了した場合は売れ残りとなり、アイテムは出品者の保管庫へ返却される
6. 入札が0件のあいだは、出品者はいつでも出品を取り消せる(出品料は返らない)

## 対象外の機能

- 「買います」募集(逆オークション)
- カテゴリによる絞り込み(並び替えのみ)
- 評価・星機能
- QuickShop-Hikariとの連携・置き換え
- Discordへの出品通知連携
- MySQL対応、BungeeCord/Velocity構成での複数サーバー連携
